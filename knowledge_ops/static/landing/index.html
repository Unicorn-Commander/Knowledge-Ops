Governance

Memory you can defend in an audit.

A knowledge base is only as trustworthy as what it lets in, who it shows things to, and what it can prove afterwards. Knowledge-Ops treats all three as product.

Scopes Visibility enforced at query time. global · personal · restricted — the same question returns different evidence for different readers. Nobody retrieves what they couldn’t already read.
Citations Source-level, span-level. Every claim traces to a real passage in a real version of a real document — open any chip and audit it down to the source.
Lineage Full version history on every page. Who changed what, when — with diffs and a review trail either way.
Review Nothing enters unvetted. Candidates pass a review queue — provenance, access, privacy, content — approve, edit, or reject, with a paper trail.
Verdicts Retrieval is heuristic, and labeled that way. Similarity scores never masquerade as verified fact — a human, or a stricter check, decides what counts as verified.
